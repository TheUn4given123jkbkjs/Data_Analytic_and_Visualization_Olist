## Introduction to Statistics 

- **Statistics** is the science of collecting, analyzing, interpreting, and presenting data. 

- It is divided into two major branches: 

   - In both branches, we work with a set of measurements. 

   - **Descriptive Statistics** – Focuses on summarizing and organizing data. 

   - **Inferential Statistics** – Uses samples to conclude populations. 

   - Inferential statistics help to draw conclusions about the population while descriptive statistics summarizes the features of the data set. 

- Why is Statistics important? 

   - It helps make informed decisions based on data. 

   - Used in business, healthcare, economics, and many other fields.

## Descriptive Statistics 

- In situations where our primary goal is to describe the data, our set of measures often covers the entire population. 

- Descriptive statistics refers to a set of methods used to summarize and describe key features of a data set: central tendency, variability, and distribution. 

- Good descriptive statistics help us understand data by reducing many measures to a small number of summary quantities. 

- These methods provide an overview of the data and help identify patterns and relationships. 

- Summarizes data through tables, graphs, and numerical measures.

## Descriptive Statistics - Examples 

- Income Distribution 

   - Suppose we want to describe the annual income distribution of all families in the 2000 census. 

   - Since data is already recorded, we don’t need sampling. 

   - Key focus: Organizing and interpreting data to find patterns and trends. 

- Applications in Different Fields 

   - Healthcare: Analyzing medical costs by illness, age, inpatient/outpatient care, etc. 

   - Economics: Monitoring inflation using indicators like the Consumer Price Index (CPI).

## Inferential Statistics 

- In situations where we cannot observe the entire population, a sample is selected from the population and suitable measurements are taken. 

- We use the information in the sample to draw conclusions about the sample’s population. 

- To appropriately estimate a population characteristic or parameter, a random and unbiased sample must be representative of the entire population. 

- There are two main types of inferential statistics - hypothesis testing and regression analysis. 

- While making inferences, we also need to organize, summarize, and describe the data.

## Histogram 

- Histograms show the distribution of quantitative data using adjacent columns. 

- The area under the histogram corresponding to a class interval indicates the percentage of values that belong to that class interval. 

- Different from column charts used to display qualitative data. A histogram displays quantitative data. 

- Histogram helps us analyze data and draw meaningful conclusions. 

- As with the pie chart, we must organize the data before constructing a graph.

## Histogram - How to Build a Frequency Table 

1. Calculate the range of variation: 42 - 17 = 25 

2. Choose the number of layers: Approximately 10 layers. 

3. Calculate class width: Divide the variation range by the desired number of class intervals, then round to a convenient unit for use. This unit will be the standard width of the class interval. we have 25/10 = 2.5 

4. Determine the class range: Choose the first-class range that contains the smallest value. To avoid confusion when classifying data, the starting point of the first interval should be set so that no value lies on the boundary between the two intervals. One way to do this is to choose a boundary with one more decimal place than the data. 

5. Count the number of occurrences in each interval.

Relationship Between Histograms and Probability 

- The probability of randomly selecting a value within an interval equals the proportion of values in that interval. 

- Example: From a sample, 82% of cows had fewer than 34 ticks. 

- This proportion estimates the likelihood that any treated cow has fewer than 34 ticks.

## Stem and Leaf Plot 

- A stem-and-leaf plot is a clever and simple tool for building a frequency distribution image similar to a histogram. 

- It allows us to use information in a frequency distribution table to show: 

   - Displays the range of scores. 

   - Identifies where the scores are concentrated. 

   - Illustrates the shape of the distribution. 

   - Checks if any values are missing. 

   - Detects any unusual or extreme values. 

- The stem-and-leaf plot does not follow the organizing principles of the histogram mentioned earlier. 

<mark>Feb 2nd, 2025</mark> 

<mark>25</mark> 

## Guidelines for Constructing Stem-and-Leaf Plots 

**1. Split each score** into two parts: 

   - The **stem** consists of the leading digits. 

   - The **leaf** consists of the trailing digit(s). 

**2. List all possible stem values** in ascending order. 

**3. Assign each score to the appropriate stem:** Write the leaf digits next to their corresponding stem value. 

**4. Adjust the display if needed:** If the plot appears too cramped, split each stem into two lines: 

   - Place leaf digits **0–4** on the first line. 

   - Place leaf digits **5–9** on the second line. 

**5. Simplify large numbers** if necessary: For long scores (e.g., six or seven digits), drop the rightmost trailing digit(s) to improve clarity. 

**6. Recognize that stem-and-leaf plots differ from traditional frequency distributions:** 

   - The way stems are formed does not strictly follow the rules for class intervals in frequency distributions. 

   - We will explore these differences further in later sections.

- A time series should include at least four or five time points, typically spaced regularly. 

- More time points are preferable to provide a more comprehensive view of how a variable evolves. 

- Time-series plots are helpful in examining general trends and seasonal or cyclic patterns.

## Time Series Trends 

- Time Series plots often represent data over time, helping to identify trends and fluctuation patterns. Key trends include: 

   - **Uptrend:** When data tends to increase over time, often seen in revenue, stock prices, or GDP. 

   - **Downtrend:** When data decreases over time, common during economic downturns or industry declines. 

   - **Cyclical Pattern:** When data fluctuates in longer cycles, it may be related to the economic cycle (growth, recession). 

   - **Seasonality:** When data fluctuates in a recurring pattern over a fixed period (monthly, quarterly, yearly). 

   - **Irregular/Random Variations:** When data does not follow any rules, often due to unexpected factors such as natural disasters or crises.
